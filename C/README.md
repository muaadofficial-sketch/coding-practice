C Programming Practice

This folder contains my C programming practice programs as a first-year Mechatronics Engineering student.

Program 1: Adding Two Numbers

File: "adding_two_numbers.c"

Objective

To read two integers from the user, calculate their sum, and display the result.

Concepts Used

- "stdio.h" and standard input/output
- Variables and integer data types
- "scanf()" and "printf()"
- Arithmetic operators
- The "main()" function

How to Run

Compile using GCC:

gcc adding_two_numbers.c -o adding_two_numbers

Run the compiled program:

./adding_two_numbers

Example Output

Enter two integers: 10 20
Sum = 30

What I Learned

I practised reading user input, performing arithmetic operations, displaying output, and organising C source code in a GitHub repository.
